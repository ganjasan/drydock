# Навык: Профили стейкхолдеров (по Вигерсу)

## Цель

Создай детальные профили всех стейкхолдеров — всех, кто влияет на продукт или на кого влияет продукт. Документ помогает команде понять, чьи требования важнее и как управлять ожиданиями.

## Категории стейкхолдеров по Вигерсу

1. **Пользователи (Users)** — напрямую работают с системой
2. **Заказчики (Customers)** — принимают решение о покупке (могут отличаться от пользователей)
3. **Спонсор (Sponsor)** — финансирует проект, отвечает за ROI
4. **Бизнес-аналитики** — собирают и документируют требования
5. **Регуляторы** — устанавливают внешние ограничения (законы, стандарты)
6. **Смежные команды** — поставщики API, зависимые системы

## Шаблон профиля одного стейкхолдера

```markdown
### [Название роли / типа стейкхолдера]

**Описание:** [Кто это? Сколько человек? Где работают?]

**Представитель:** [Имя конкретного человека / команды для уточнения требований]

**Тип участия:**
- [ ] Пользователь системы
- [ ] Заказчик / покупатель
- [ ] Спонсор
- [ ] Технический поставщик
- [ ] Регулятор

**Основные задачи, которые выполняет с системой:**
1. [Задача 1]
2. [Задача 2]

**Требования к системе (от их имени):**
- [Требование 1]
- [Требование 2]

**Критерии успеха для этого стейкхолдера:**
- [Что для него означает "система работает хорошо"]

**Болевые точки текущего решения:**
- [Что сейчас не устраивает]

**Ограничения и предпочтения:**
- Техническая грамотность: [Новичок / Средний / Эксперт]
- Язык: [Русский / Английский / ...]
- Доступность для интервью: [Высокая / Средняя / Низкая]

**Влияние на проект:** [Высокое / Среднее / Низкое]
**Интерес к проекту:** [Высокий / Средний / Низкий]
```

## Матрица влияние × интерес

После описания всех стейкхолдеров построй матрицу:

```
ВЛИЯНИЕ
  ^
В |  [Управляй]    |  [Вовлекай]   |
  |  (низкий инт.) |  (высокий инт.)|
С |  [Наблюдай]   |  [Информируй]  |
  |                |                |
Н +----------------+-----------------> ИНТЕРЕС
                   С                В
```

- **Вовлекай** (высокое влияние + высокий интерес): ключевые стейкхолдеры
- **Управляй** (высокое влияние + низкий интерес): держи в курсе, не перегружай
- **Информируй** (низкое влияние + высокий интерес): регулярные обновления
- **Наблюдай** (низкое влияние + низкий интерес): минимальные усилия

## Вопросы для интервью со стейкхолдером

1. Какова ваша роль и как вы используете текущую систему?
2. Какие задачи занимают больше всего времени?
3. Что работает хорошо в текущем решении?
4. Что вас больше всего раздражает?
5. Как будет выглядеть ваш рабочий день после внедрения новой системы?
6. Что должно произойти, чтобы вы считали проект успешным?
7. Есть ли ограничения (технические, юридические, операционные), о которых мы должны знать?
