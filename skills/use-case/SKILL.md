# Навык: Варианты использования (Use Cases)

## Цель

Создай детальный вариант использования по шаблону Вигерса / Алистера Кокберна. Use Case описывает взаимодействие актора с системой для достижения цели — без деталей реализации.

## Уровни детализации Use Cases (по Кокберну)

- **Кратко (Brief)**: 1 абзац, цель + основной поток
- **Небрежно (Casual)**: несколько абзацев, включая альтернативы
- **Полностью (Fully Dressed)**: полный шаблон ниже

## Полный шаблон Use Case

```markdown
### UC-[N]: [Название варианта использования]

**Уровень:** [Цель пользователя / Подфункция / Обзорный]
**Приоритет:** [Высокий / Средний / Низкий]
**Актор:** [Кто инициирует взаимодействие]
**Связанные требования:** [FE-N, BO-N]

---

**Краткое описание:**
[1–2 предложения: кто + что делает + зачем]

**Предусловия:**
- [Что должно быть истинным до начала UC]

**Постусловия (успех):**
- [Состояние системы после успешного выполнения]

**Постусловия (неудача):**
- [Состояние системы при провале]

---

**Основной поток (Happy Path):**

| # | Актор | Система |
|---|-------|---------|
| 1 | [Действие актора] | |
| 2 | | [Реакция системы] |
| 3 | [Действие актора] | |
| 4 | | [Реакция системы] |

---

**Альтернативные потоки:**

**[A1] [Название альтернативы]:**
- На шаге [N]: [Условие альтернативы]
  - [Шаги альтернативного потока]
  - Возврат к шагу [N] / Завершение

**Потоки исключений:**

**[E1] [Название исключения]:**
- На шаге [N]: [Условие ошибки]
  - Система показывает [сообщение об ошибке]
  - [Дальнейшие действия]

---

**Бизнес-правила:**
- BR-[N]: [Применяемое бизнес-правило]

**Открытые вопросы:**
- [ ] [Вопрос, требующий уточнения]
```

## Чеклист качества Use Case

- [ ] Название — глагол + существительное от лица актора (не системы)
- [ ] Основной поток имеет 3–9 шагов
- [ ] Каждый шаг — одно действие (не несколько)
- [ ] Нет деталей UI ("нажимает кнопку Сохранить" → "подтверждает операцию")
- [ ] Нет деталей реализации ("система записывает в БД" → "система сохраняет заказ")
- [ ] Все альтернативы ссылаются на конкретный шаг основного потока
- [ ] Предусловия проверяемы
